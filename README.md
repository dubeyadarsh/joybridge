# JoyBridge Landing Page

A warm, trustworthy static landing page for a social impact platform connecting donors with orphanages through event sponsorship and micro-donations.

## Quick Start

Open `index.html` directly in a browser, or serve locally:

```bash
npx serve .
```

Then visit `http://localhost:3000`.

## Features

- Responsive mobile-first layout with hamburger navigation
- Smooth scroll anchor links
- Filterable event sponsorship grid (Sports, Creative & Arts, Entertainment)
- Interactive checkout modal with dynamic pricing and breakdown
- Certificate preview modal
- Animated impact counters
- In-person attendance toggles on event cards

## Tech Stack

- HTML5
- Tailwind CSS (CDN)
- Vanilla JavaScript
- Plus Jakarta Sans typography

## File Structure

```
index.html   — Page structure and content
styles.css   — Custom component styles
app.js       — Interactivity (modals, filters, scroll, counters)
```
